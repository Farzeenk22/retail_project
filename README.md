# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project: cleaning and feature engineering a raw retail dataset with **Python (pandas)**, answering business questions with **SQL (MySQL)**, and visualizing results in a **Power BI** dashboard.

---

## 📌 Project Overview

This project analyzes customer shopping behavior to understand revenue drivers, discount effectiveness, shipping preferences, subscription impact, and customer loyalty.

**Workflow**

1. Load the raw dataset with pandas
2. Clean and wrangle the data
3. Engineer new features
4. Export the cleaned dataset and load it into MySQL
5. Solve business queries using SQL
6. Build a Power BI dashboard

## 🧹 Data Cleaning & Wrangling (Python)

- **Standardized column names** for consistency (clean, uniform naming)
- **Handled missing values** by filling them with the **group-wise median**
- **Removed redundant column:** `discount_applied` and `promo_code_used` were found to be identical, so `promo_code_used` was dropped

## ⚙️ Feature Engineering

- **Age Category** – created from the integer `age` column
- **Purchase Frequency in Days** – converted the text-based frequency of purchases into numeric days

The final cleaned dataset (3,900 rows × 19 columns) was saved and loaded into MySQL for analysis.

## 🔍 Key Insights

Total revenue across all 3,900 customers is **233,081**.

### 1. Revenue by Gender
| Gender | Revenue | Share |
|---|---|---|
| Male | 157,890 | ~67.7% |
| Female | 75,191 | ~32.3% |

Male customers generate roughly **twice** the revenue of female customers.

### 2. Highest Rated Products (Average Review Rating)
| Rank | Product | Avg Rating |
|---|---|---|
| 1 | Gloves | 3.86 |
| 2 | Sandals | 3.84 |
| 3 | Boots | 3.82 |
| 4 | Hat | 3.80 |
| 5 | Skirt, T-shirt, Handbag (tie) | 3.78 |

Ratings across products are very close (3.76 to 3.86), so no single product stands out strongly.

### 3. Subscribers vs. Non-Subscribers
| Subscription | Customers | Avg Spend | Total Revenue |
|---|---|---|---|
| Yes | 1,053 | 59.49 | 62,645 |
| No | 2,847 | 59.87 | 170,436 |

Subscribers **do not spend more** per purchase: average spend is almost identical (59.49 vs 59.87). Non-subscribers bring in more total revenue simply because there are far more of them (about 73% of customers).

### 4. Revenue Contribution by Age Group
| Age Group | Revenue | Share |
|---|---|---|
| Young adults | 62,143 | ~26.7% |
| Middle age | 59,197 | ~25.4% |
| Adults | 55,978 | ~24.0% |
| Seniors | 55,763 | ~23.9% |

Young adults contribute the most revenue, but the gap is small: revenue is spread fairly evenly across all four age groups.

## ▶️ How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/Farzeenk22/retail_project.git
   cd retail_project
   ```
2. Install dependencies
   ```bash
   pip install pandas sqlalchemy pymysql
   ```
3. Run `retail.ipynb` to clean the data (update the MySQL password placeholder in the connection cell)
4. Make sure MySQL is running; the notebook loads the cleaned data into the `retailproj` database
5. Run the queries in `retailprj.sql` using MySQL Workbench
6. Open `customer_behavior.pbix` in Power BI Desktop, or view `dashboard.pdf`
